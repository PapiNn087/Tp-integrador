1. Nombre del proyecto

TECHSTORE – Tienda online de componentes informáticos.

2. Descripción del sitio

TECHSTORE es un sitio web diseñado para una tienda ficticia dedicada a la venta de componentes y accesorios para computadoras.

El objetivo del proyecto es ofrecer una página sencilla e intuitiva donde los usuarios puedan explorar diferentes productos, consultar sus precios y encontrar componentes según sus necesidades.

El sitio cuenta con un catálogo de productos, buscador, filtros por categoría y rango de precios, un carrusel automático de productos destacados, una tabla comparativa, una sección informativa sobre la tienda y un formulario de contacto.

Para el diseño visual se utilizó una estética moderna con fondo oscuro, degradados de colores, tarjetas con efecto glassmorphism, bordes redondeados y animaciones.

4. Instrucciones para visualizar el proyecto

Descargar o descomprimir la carpeta del proyecto TECHSTORE.

Verificar que se mantenga la estructura de carpetas y archivos.

Abrir la carpeta del proyecto con Visual Studio Code.

Comprobar que estén presentes los siguientes archivos:

index.html

nosotros.html

contacto.html

styles.css

javascript.js

Abrir el archivo index.html utilizando la extensión Live Server de Visual Studio Code.

Desde el menú de navegación se puede acceder a las diferentes páginas del sitio.

Nota: Se recomienda contar con conexión a Internet para cargar correctamente las tipografías de Google Fonts y las imágenes externas utilizadas en los productos.
